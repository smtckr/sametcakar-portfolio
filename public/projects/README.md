# Proje Görselleri Dizini

Bu dizine (`/public/projects/`) gerçek çalışmalarınızın ekran görüntülerini, video kapaklarını veya render çıktılarını koyabilirsiniz.

Örnek dosya isimleri:
- `arcelik-beko-video.jpg` -> Arçelik & Beko Eğitim Videosu
- `comfyui-flux2.png` -> ComfyUI & Flux2 İş Akışı
- `kurgu-plugin.png` -> Premiere / Final Cut AI Kurgu Eklentisi
- `h3-seedance.jpg` -> H3 & Seedance AI Video
- `web-arayuz.png` -> Web Arayüzleri
- `sosyal-medya.jpg` -> Sosyal Medya Çalışmaları

Bu dosyalar Vite tarafından doğrudan `/projects/dosya-adi.jpg` adresiyle sunulur.
